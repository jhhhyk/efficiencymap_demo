## 문제 정의

대학가 인근으로 전월세 수요가 집중되면서 수요·공급 불균형이 발생하고, 이는 인근 지역의 전월세가 상승과 주거의 질 하락으로 이어집니다.

사용자 조사 결과, 이 문제의 원인 중 하나는 **인지적 오류**였습니다.

- 학생들은 통학 소요시간을 학교와의 **직선거리에 비례한다고 인지**합니다.
- 그러나 실제 대중교통 소요시간은 직선거리와 비례하지 않습니다. 직선거리가 먼 외곽 지역 중에도 소요시간이 짧은 구역이 존재합니다.
- 이 인지적 오류 때문에 매물 탐색 과정에서 특정 지역이 **선제적으로 제외**되며, 조사에서 지역 제외 사유의 81%가 통학 소요시간에 대한 우려였습니다.

기존 서비스는 이 격차를 메우지 못합니다. 부동산 중개 앱은 매물 정보는 제공하지만 통학 시간 정보가 없고, 지도 앱은 교통 정보는 있지만 매물 정보가 없습니다. 사용자가 두 정보를 직접 대조해야 하는 진입장벽이 존재합니다.

**실제 소요시간을 함께 제시하면 선택이 달라집니다.** Before/After 실험에서, 직선거리가 가장 먼 매물의 선호도가 실제 통학 시간 정보를 제공한 뒤 지불의사금액(WTP) 기준 약 22만 원 상승했습니다. 이 프로젝트는 그 정보 격차를 해소하는 것을 목표로 합니다.

## 접근 방법

정성적인 주거 선택 요인을 정량 모형으로 구조화한 뒤, 이를 실거래가 데이터 및 공간 시각화와 결합했습니다.

### 1단계 · 사용자 조사

| 기법 | 목적 | 결과 |
|---|---|---|
| 이산선택실험 (DCE) | 잠재적 선호 파악 | 4개 속성 30개 조합을 직교설계로 15문항 최적화 |
| 조건부 로짓 모형 | 효용계수 추정 | 최대우도추정으로 속성별 계수 산출 |
| AHP | 결정요인 상대 중요도 | 6개 요인 쌍대비교, 일관성비율(CR) 0.018 |

**주요 발견**

- 월세와 통학 시간의 응답 비율이 전체의 50%를 초과하는 지배적 결정요인
- 통학 시간 상한선을 30분 이하로 잡은 응답자가 90.3%
- 통학 시간 10분 단축의 가치 = 월 15.6만 원 (**15,600원/분**)

### 2단계 · 지표 설계

돈(임대료)·시간(통학)·면적이라는 이질적인 변수를 하나의 척도로 통합하기 위해, 단위 면적당 총 효용 비용 산출식을 고안했습니다.

### 3단계 · 공간 적용

인근 지역 전월세 실거래 5,073건을 전수조사해 지표를 적용하고, 지도 위에 색상으로 시각화했습니다.

## 효율지표

### 산출식

```
면적당 주거비용   P_m²  =  ( R + D × i / 12 ) / A

효율지수         E     =  ( R + D × i / 12 + T × α ) / A
```

| 기호 | 항목 | 설명 |
|---|---|---|
| `R` | 직접 비용 | 매월 실제로 지출되는 월 임대료 |
| `D × i / 12` | 보증금의 기회비용 | 보증금이 부동산에 묶임으로써 포기하는 금융 수익. 연 이자율 `i = 0.06` 적용 |
| `T × α` | 통학 시간의 그림자 가격 | 기대 소요시간에 시간의 가치를 곱해 화폐 단위로 환산. `α = 15,600원/분` |
| `A` | 전용면적 (㎡) | 단순 총액 비교의 오류를 피하기 위해 면적으로 나누어 공간 단위당 효율을 산출 |

`α`는 임의로 정한 값이 아니라, 앞선 이산선택실험에서 추정된 시간-비용 대체율에서 도출한 값입니다.

### 계산 예시

| 항목 | 값 |
|---|---|
| 보증금 | 5,000만 원 |
| 월세 | 100만 원 |
| 전용면적 | 29.25㎡ |
| 기대 소요시간 | 24.3분 |

```
보증금 기회비용 = 50,000,000 × 0.06 / 12 = 250,000원
통학 시간 비용  = 24.3 × 15,600          = 378,700원

P_m² = (1,000,000 + 250,000) / 29.25             = 42,735원/㎡
E    = (1,000,000 + 250,000 + 378,700) / 29.25   = 55,683원/㎡
```

### 해석

**값이 낮을수록 우수한 매물입니다.**

| 구간 | 의미 |
|---|---|
| High Efficiency Zone (녹색) | 임대료가 저렴하거나 통학 시간이 짧아 종합 비용이 최소화되는 저평가 우량 매물 |
| Low Efficiency Zone (적색) | 높은 임대료 또는 과도한 통학 시간으로 투입 비용 대비 효용이 낮은 고평가 매물 |

### 수집 및 가공 과정

```
1. 건축물 타겟팅
   국토교통부 건축물대장 API
   → 단독주택·아파트를 제외한 다세대·다가구·연립·오피스텔 추출

2. 시장가격 매핑
   서울시 전월세 실거래가 API
   → 보증금(D), 월세(R), 전용면적(A)

3. 지오코딩
   Kakao Geocoding API
   → 주소를 WGS84 좌표계 위경도로 변환

4. 소요시간 산출
   ODsay API
   → 도보 시간과 대중교통 기대 소요시간을 비교해 최소값 선택

5. 지표 산출
   → 면적당 주거비용(P_m²) 및 효율지수(E) 계산

6. GeoJSON 변환
   → 5,073건의 FeatureCollection
```

### 기대 소요시간 산출

단순 이동 시간이 아니라, 정류장에서의 **예상 대기시간까지 포함한 현실적인 평균 소요시간**을 사용합니다.

```
T_transit = t_access + t_ride + t_egress + t_wait
```

| 항목 | 의미 |
|---|---|
| `t_access` | 출발지에서 승차 정류장까지 도보 시간 |
| `t_ride` | 차량 탑승 시간 |
| `t_egress` | 하차 정류장에서 목적지까지 도보 시간 |
| `t_wait` | 해당 경로의 노선별 배차 간격(`H_k`) 조합으로 산출한 기대 대기시간 |

목적지까지 가능한 여러 경로의 소요시간을 산출한 뒤 최소값을 반환하며, 도보만으로 가는 것이 더 빠른 경우에는 대중교통 계산을 생략합니다. 전체 5,073건 중 407건이 도보 우위 매물입니다.

## 실행 방법

### 프론트엔드

정적 사이트이므로 별도 빌드가 필요하지 않습니다.

```bash
cd frontend
python -m http.server 5500
```

브라우저에서 `http://localhost:5500` 접속.

### 백엔드

경로 조회 기능을 사용하려면 백엔드가 필요합니다.

```bash
cd backend
python -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\activate
pip install -r requirements.txt

cp .env.example .env          # ODSAY_API_KEY 입력
uvicorn main:app --port 8000
```

> ODsay API는 IP 화이트리스트 방식이므로, 호출하는 서버의 IP를 ODsay 콘솔에 등록해야 합니다.
